# Pink Frequency · Dream Machine

Музыкальный веб-инструмент начального уровня на React и Tone.js. Два самостоятельных голоса: Velvet Bass (монофонический бас с 16-шаговым секвенсором) и Gloss Lead (полифоническая мелодия, до 16 синтезируемых голосов). Barbiecore-оформление: Arial, Georgia Italic, розовые градиенты и малиновые акценты.

## Запуск исходников

Требуется Node.js 22 или новее.

```bash
npm ci
npm run dev
```

Открой адрес, который выведет терминал. `npm run build` собирает готовый сайт в `dist`; `npm run preview` позволяет проверить сборку. Открытие исходного index.html двойным щелчком не запускает React-проект: используй сервер Vite или опубликованную версию.

## Публикация в GitHub Pages

Здесь предусмотрены два способа. Выбери один:

1. **Исходники + GitHub Actions (рекомендуется для сдачи).** Замени старые файлы репозитория содержимым папки `source`, включая `src`, `package.json`, `package-lock.json`, `vite.config.js`, `.gitignore` и `.github/workflows/pages.yml`. Старые корневые `script.js` и `style.css` больше не используются — удали их. Не загружай `node_modules`. В Settings → Pages выбери Source → GitHub Actions. После коммита в main workflow соберёт и опубликует сайт. Это сохраняет читаемые React-компоненты в репозитории.
2. **Готовый сайт без установки пакетов.** Загрузи содержимое папки `ready-to-upload` (index.html и папку assets) в корень отдельного репозитория. В Pages выбери Deploy from a branch → main → /(root). Вариант годится для просмотра; для проверки структуры кода преподавателем приложи исходники отдельно.

Если репозиторий уже содержит старую версию, сохрани её в истории Git. Перед заменой можно скачать её архивом через Code → Download ZIP. Новая версия не была автоматически отправлена в твой GitHub.

## Звуковая архитектура

- Velvet Bass: Tone.MonoSynth (осциллятор, амплитудная огибающая и внутренний фильтр с огибающей) → Tone.Filter (low-pass, бегунок «Фильтр») → Tone.Distortion → Tone.Channel 01.
- Gloss Lead: Tone.PolySynth(Tone.Synth) → Tone.Filter (low-pass) → Tone.FeedbackDelay (синхронная восьмая, feedback 0.28) → Tone.Reverb (decay 2 s) → Tone.Channel 02.
- Каждый канал имеет отдельную громкость, панораму и Mute. Оба подключены к общему Tone.Limiter (−3 dB), затем к общей громкости и стереовыходу. Tone.Waveform считывает мастер-сигнал для визуализации.
- Бегунок «Дисторшн» регулирует долю обработанного сигнала (wet); величина distortion фиксирована 0.25. «Эхо» и «Реверберация» также управляют wet.
- Секвенсор: Tone.Loop с интервалом 16n; визуальная подсветка синхронизирована через Tone.Draw. Темп 60–180 BPM.
- «Затухание» — release, длительность после отпускания клавиши. Атака и release независимы для баса и мелодии.

## Компоненты

`src/main.jsx` — App, транспорт, микшер и состояние интерфейса.
`src/audio/engine.js` — SynthEngine: инициализация аудио, соединения, транспорт, запуск и отпускание нот.
`src/components/Controls.jsx` — Slider и VoicePanel.
`src/components/Keyboard.jsx` — клавиши, мышь, касания, компьютерная клавиатура, защита от зависших нот при потере фокуса.
`src/components/Sequencer.jsx` — 16 шагов и выбор высоты нот.
`src/presets.js` — начальные настройки, три настроения, басовый рисунок и демо-мелодия.
`src/style.css` — визуальные токены и адаптивные стили.

## Управление и короткий сет (около 60 секунд)

1. Убавь громкость устройства, надень наушники. Нажми «Играть»: запустится басовый рисунок в 112 BPM.
2. Первые 8–10 секунд оставь только бас. Плавно открывай его фильтр.
3. Играй мелодию A D G D H G D S; соответствие нотам C E G E A G E D. Несколько клавиш дают аккорд. Клавиши определяются по физическому положению и работают в русской раскладке.
4. Если нужна демонстрация без навыка игры, включи «Демо-мелодия»: она зацикливается синхронно с басом. Для живого сета меняй фильтры, эффекты, панораму и Mute вручную.
5. На 25–30 секунде переключи Gloss: звучание станет ярче. Увеличь эхо мелодии. Измени пару нот в секвенсоре.
6. На 40–45 секунде выключи бас через Mute, оставь мелодию. Затем верни бас и выбери Velvet.
7. Снизь общую громкость и нажми «Стоп». Эффекты могут оставить короткий хвост — это естественно.

«Остановить» и «Стоп» возвращают секвенсор к первому шагу. «Снять ноты» отпускает активные ноты, но не выключает секвенсор. После изменения бегунка щёлкни на заголовке, чтобы играть буквами; на самих кнопках Enter и Space играют соответствующую ноту. Октавы мелодии: 2–6.
